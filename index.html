0–3 minutes

HTML Foundations

Books 01 · 02 · 06

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My HTML Website</title>
</head>
<body>
    <header>
        <h1>My Website</h1>
        <nav aria-label="Main navigation">
            <a href="index.html">Home</a>
            <a href="about.html">About</a>
            <a href="contact.html">Contact</a>
        </nav>
    </header>
    <main>
        <section>
            <h2>Welcome</h2>
            <p>I am learning <strong>HTML</strong>.</p>
        </section>
    </main>
    <footer>
        <p>&copy; 2026 My Website</p>
    </footer>
</body>
</html>
<!DOCTYPE html>
Uses modern HTML mode.
html lang="en"
Root element; declares English.
head
Page settings and metadata.
body
Visible page content.
h1–h6
Headings: organize levels logically.
p
A paragraph.
strong
Marks importance.
header
Introductory content.
nav
Major navigation links.
main
The page’s main content.
section
A themed group, usually with a heading.
footer
Closing information.

3–5 minutes

Links, Images & File Paths

Books 03

<a href="about.html">About Me</a>
<a href="https://example.com">Visit Website</a>
<img src="images/profile.jpg" alt="Portrait of the portfolio author" width="300">
about.html
Same folder as the current page.
images/profile.jpg
Inside the images folder.
../images/profile.jpg
Go up one folder, then into images.

href is a link destination; src locates media. Describe the actual image in alt.

Lists & Tables

Books 04

<h2>My Skills</h2>
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
<table>
    <caption>My technology levels</caption>
    <thead>
        <tr>
            <th scope="col">Technology</th>
            <th scope="col">Level</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>HTML</td>
            <td>Advanced</td>
        </tr>
        <tr>
            <td>CSS</td>
            <td>Beginner</td>
        </tr>
    </tbody>
</table>
ul / ol
Unordered bullets / ordered steps.
li
One list item.
table
Tabular data, not page layout.
caption
The table’s title.
thead / tbody
Header rows / data rows.
tr
A table row.
th
A header cell; scope="col" identifies a column header.
td
A data cell.

7–10 minutes

Forms & Validation

Books 05 · 08

<form action="/contact" method="post">
    <label for="name">Name</label>
    <input type="text" id="name" name="name"
           minlength="3" maxlength="100" autocomplete="name" required>

    <label for="email">Email</label>
    <input type="email" id="email" name="email"
           autocomplete="email" required>

    <label for="message">Message</label>
    <textarea id="message" name="message" required></textarea>

    <button type="submit">Send Message</button>
</form>

action sets the receiving URL; method="post" sends data in the request body. Each name is a submitted field key; for connects a label to an input’s id.

required
Must be filled in.
minlength="3" / maxlength="100"
Text length limits.
min="1" / max="10"
Number or date bounds (use valid dates for date inputs).
placeholder="Enter your name"
A hint, never a replacement for a label.
autocomplete="name"
Helps the browser fill a name.
type="email"
Checks basic email format.
type="date"
A date input.
type="number"
A numeric input.
type="file"
A file picker; uploads need method="post" and enctype="multipart/form-data". 
<label for="rating">Rating (1–10)</label>
<input type="number" id="rating" name="rating" min="1" max="10">

This is a static practice project: /contact needs a backend. Browser validation helps users; validate again on the server. POST alone does not encrypt data—use HTTPS.

10–11 minutes

Multimedia

Books 07

<audio controls preload="none">
    <source src="audio/music.mp3" type="audio/mpeg">
    Your browser does not support audio.
</audio>

<video controls width="500" preload="none">
    <source src="videos/demo.mp4" type="video/mp4">
    Your browser does not support video.
</video>

controls adds playback buttons. source supplies the file and MIME type. preload="none" avoids requesting media in advance. Fallback text is for browsers that do not support the element.

Use your own instrumental audio and silent demo video for this sample. For speech, provide a transcript and video captions using <track kind="captions">; describe meaningful visual information too.

11–12 minutes

Metadata, SEO & Social Sharing

Books 09

Place these inside <head>.

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>HTML Developer Portfolio</title>
<meta name="description" content="My personal web development portfolio.">
<meta property="og:title" content="HTML Developer Portfolio">
<meta property="og:description" content="View my web development projects.">
charset
UTF-8 supports a wide range of characters.
title
Identifies the page in browser tabs and search results.
description
Summarizes the page; search engines may use it as a snippet.
viewport
Makes the layout viewport match the device width.
og:title / og:description
Suggest a title and description for social link previews.

12–13 minutes

Accessibility

Books 10

<label for="email">Email Address</label>
<input id="email" name="email" type="email">

<img src="images/student.jpg" alt="Student working on a laptop">
<img src="images/decoration.svg" alt="">

<html lang="en">

<h1>Main Title</h1>
<h2>About</h2>
<h3>Our History</h3>

These are separate examples: set lang on the document’s existing root. Informative images need meaningful alt text; decorative images use alt="". The student and decoration images are illustrative paths, not required sample assets.

Keep headings in a logical hierarchy. Use native links, buttons, and controls. Test with Tab, Shift+Tab, Enter, and Space; keep keyboard focus visible.

13–14 minutes

Advanced HTML

Books 11

<details>
    <summary>What is HTML?</summary>
    <p>HTML provides the structure and meaning of web content.</p>
</details>

<label for="learning">Learning progress</label>
<progress id="learning" value="70" max="100">70%</progress>

<label for="score">Quiz score</label>
<meter id="score" min="0" max="100" value="85">85%</meter>
details / summary
A native expandable disclosure and its label.
progress
Completion of a task.
meter
A measurement within a known range, such as a score.

Browser APIs such as geolocation and storage require JavaScript; HTML supplies the elements they can work with.

Final complete example

Save this as html-revision/index.html. This is plain HTML: the revision guide’s styling is not needed. Add the media files and supporting pages shown above. 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>HTML Developer Portfolio</title>
    <meta name="description" content="My personal web development portfolio.">
    <meta property="og:title" content="HTML Developer Portfolio">
    <meta property="og:description" content="View my web development projects.">
</head>
<body>
    <header>
        <h1>My HTML Portfolio</h1>
        <nav aria-label="Main navigation">
            <a href="index.html" aria-current="page">Home</a>
            <a href="about.html">About</a>
            <a href="contact.html">Contact</a>
        </nav>
    </header>

    <main>
        <section>
            <h2>Welcome</h2>
            <p>I am learning <strong>HTML</strong> and building my first website.</p>
            <img src="images/profile.jpg" alt="Portrait of the portfolio author"
                 width="300" height="300">
            <p><a href="https://example.com">Visit Website</a></p>
        </section>

        <section>
            <h2>My Skills</h2>
            <ul>
                <li>HTML</li>
                <li>CSS</li>
                <li>JavaScript</li>
            </ul>
            <table>
                <caption>My technology levels</caption>
                <thead>
                    <tr>
                        <th scope="col">Technology</th>
                        <th scope="col">Level</th>
                    </tr>
                </thead>
                <tbody>
                    <tr>
                        <td>HTML</td>
                        <td>Advanced</td>
                    </tr>
                    <tr>
                        <td>CSS</td>
                        <td>Beginner</td>
                    </tr>
                </tbody>
            </table>
        </section>

        <section>
            <h2>Media</h2>
            <audio controls preload="none">
                <source src="audio/music.mp3" type="audio/mpeg">
                Your browser does not support audio.
            </audio>
            
            <video controls width="500" preload="none">
                <source src="videos/demo.mp4" type="video/mp4">
                Your browser does not support video.
            </video>
            <p>Audio: instrumental music. Video: a silent demonstration of this portfolio.</p>
        </section>

        <section>
            <h2>Learning</h2>
            <details>
                <summary>What is HTML?</summary>
                <p>HTML provides the structure and meaning of web content.</p>
            </details>
            
            <label for="learning">Learning progress</label>
            <progress id="learning" value="70" max="100">70%</progress>
            
            <label for="score">Quiz score</label>
            <meter id="score" min="0" max="100" value="85">85%</meter>
        </section>

        <section id="contact">
            <h2>Contact Me</h2>
            <p>Practice only: sending requires a server endpoint at /contact.</p>
            <form action="/contact" method="post">
                <label for="name">Name</label>
                <input type="text" id="name" name="name"
                       minlength="3" maxlength="100" autocomplete="name" required>
            
                <label for="email">Email</label>
                <input type="email" id="email" name="email"
                       autocomplete="email" required>
            
                <label for="message">Message</label>
                <textarea id="message" name="message" required></textarea>
            
                <button type="submit">Send Message</button>
            </form>
        </section>
    </main>

    <footer>
        <p>&copy; 2026 My Website</p>
    </footer>
</body>
</html>
